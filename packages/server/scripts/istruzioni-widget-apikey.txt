# Elenca chiavi esistenti
  pnpm generate-apikey --list

# Revoca una chiave
  pnpm generate-apikey --revoke 4f0b3a1f-343d-464b-bd2d-c9d771b1b72c

Punto importante: nessun legame diretto Widget→ApiKey

Nel modello attuale, le API key sono user-scoped (associate all'utente admin che le crea), non widget-scoped. Qualsiasi
chiave API valida viene accettata da /api/internal/widget/* — non c'è un controllo che la chiave appartenga a un widget
specifico. Se vuoi aggiungere questo legame (es. campo apiKeyId nel modello Widget), dimmelo e lo implementiamo.

  pnpm generate-apikey
